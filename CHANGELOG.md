# Changelog

This changelog is **generated automatically by
[git-cliff](https://git-cliff.org)** from
[Conventional Commits](https://www.conventionalcommits.org) at each release
(Keep a Changelog layout, SemVer via the `version` workflow).

- **Per-release notes**: see the [Releases
  page](https://github.com/Golmet/golmet-cli/releases) — each release ships
  its section as notes plus the full generated `CHANGELOG.md` as an asset.
- **Contribution rules**: Conventional Commits are enforced by CI
  (`feat` → minor, `fix` → patch, `!`/`BREAKING CHANGE:` → major, other
  types don't cut a release) — see [CONTRIBUTING.md](CONTRIBUTING.md).
