# Roadmap

The milestone plan and its state live in [CHANGELOG.md](CHANGELOG.md) — each
wave (`M*`) documents what shipped and why. The milestone ladder:

| Milestone | Scope | State |
| --- | --- | --- |
| **F1** | The full CLI, the MCP server, the FORMAT v1 contract and the L0–L3 content layers | shipped on the `release/v1.0.0` branch (v1.0.0 release) |
| **F2** | The documentation site (the `docs/` tree rendered — the repo is the source) and a dogfooding case study | planned |
| **F3** | The contribute flow and workspace migration tooling | planned |

The normative contract is [docs/FORMAT.md](docs/FORMAT.md).
