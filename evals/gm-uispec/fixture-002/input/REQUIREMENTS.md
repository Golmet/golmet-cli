# REQUIREMENTS - Assistência Técnica (Módulo Chamados)

## Requisitos de Negócio

### RN-001

**Regra:** Quando o técnico de campo concluir o atendimento de um chamado,
então o sistema deve exigir ao menos uma foto do equipamento e o relatório
preenchido antes de permitir a conclusão.

### RN-002

**Regra:** Quando o supervisor atribuir um chamado aberto a um técnico,
então o sistema deve notificar o técnico atribuído e registrar a data da
atribuição.

### RN-003

**Regra:** O cliente solicitante deve consultar o status atual do seu
chamado sem autenticação completa, usando o código do chamado.
