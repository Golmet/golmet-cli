# REQUIREMENTS - Financiamento (Módulo Simulação)

## Requisitos de Negócio

### RN-001

**Regra:** Quando o produtor solicitar uma simulação com valor acima do
limite disponível, então o sistema deve exibir a mensagem de limite
insuficiente e registrar a tentativa.

### RN-002

**Regra:** A interface da simulação deve ser bonita e intuitiva para o
produtor.
