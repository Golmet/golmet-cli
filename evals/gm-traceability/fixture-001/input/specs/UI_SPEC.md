# UI Spec — MeuApp (módulo Relatórios)

> **Última atualização:** 05/10/2026

## Atores

- Usuário autenticado (operador de relatórios)

## Telas

### Tela: Relatórios

- Lista de relatórios disponíveis; abre um relatório ao clicar.

### Tela: Visualização do Relatório (RN-001, RN-002)

- Filtros de período com data inicial e data final (RN-002).
- Botão **Exportar PDF** no canto superior direito (RN-001).
- Após gerar, o link de download aparece na área **Minhas Exportações** e
  vale por 24 horas (RN-001).
- Checkbox **Incluir totalizador** no diálogo de exportação (CR-001).
