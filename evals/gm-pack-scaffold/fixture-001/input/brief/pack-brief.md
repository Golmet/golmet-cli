# Brief do pack — MeuApp

Decisões do operador (uma rodada única agrupada) para o onboarding do pack
da organização no ecossistema do kit:

- **Organização:** Minha Organização
- **Id do pack:** `meuapp`
- **Org GitHub:** `minha-org`
- **Repo:** `minha-org/pack-meuapp` (default `<org>-pack-<id>` aceito)
- **Visibilidade:** privado; se tornar-se público, aplicar o topic GitHub
  `golmet-pack` (convenção de descoberta da comunidade)
- **Componentes iniciais:** 1 skill de exemplo (`gm-resumo`) + README
- **accumulation:** padrões e métricas (esqueleto com README)

O pack carrega componentes do produto MeuApp que a organização quer
compartilhar entre workspaces de qualquer engine.
