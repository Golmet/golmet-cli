# Transcrição — primeira conversa de intake (MeuApp)

**Data:** 05/10/2026
**Participantes:** Ana (analista), Bruno (cliente)

**Bruno:** Quero controlar o agendamento das salas de reunião da empresa.
O produto vai se chamar MeuApp. O tracker é o #402.

**Ana:** Quais funcionalidades entram na primeira entrega?

Equipamentos ficam para depois.

**Ana:** Quem são os stakeholders — patrocinador, PO, lead técnico?

próximo mês; depois eu te passo os nomes e os papéis.

**Ana:** E os repositórios do produto — como o código vai ser organizado?

**Bruno:** Não temos repositório definido. Comecei achando que era um app
só, mas ouvi falar para separar em MeuApp-Web e MeuApp-API. Não decidi
nada; posso mudar de ideia até o fim do mês.

**Ana:** O charter precisa das duas coisas (§1 repos e §6 stakeholders) —
sem inventar dados não dá para abrir o projeto hoje.

**Bruno:** Combinei. Te procuro quando fechar isso.
