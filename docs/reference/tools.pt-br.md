O **caminho humano** é o CLI no terminal ([commands.pt-br.md](commands.pt-br.md)) - as mesmas operações, desenhadas para gestão direta.  O servidor MCP (`golmet mcp`) expõe **13 tools** `gm_*` — o mesmo kit que as skills agentic usam, direto pelo protocolo. Regra transversal de mutação: ferramentas de MUTAÇÃO (`gm_update`, `gm_pack_update`, `gm_pack_publish`, `gm_upgrade`) exigem `confirm=true` — sem o confirm elas falham com a mensagem explícita ("exige confirm=true; nenhuma alteração foi aplicada") e `dry_run` lista sem aplicar.  | Tool | Escopo | Contrato | | --- | --- | --- | | `gm_validate` | workspace | O payload do `golmet validate` (erros/avisos §11 + contadores + o contexto: container/workspace-produto).
